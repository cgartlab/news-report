# news-report 触发提示词

## 触发条件

当用户发送以下类型的消息时，执行 news-report skill：

- 请求资讯收集、筛选、汇报
- 请求跑一遍信息采集
- 请求搜索特定领域最新动态
- 请求生成资讯报告

## 典型触发句

- 「跑一遍资讯汇报」
- 「帮我收集最近的资讯」
- 「搜一下最近的 AI + 设计动态」
- 「本周有什么值得关注的资讯」
- 「做一下资讯筛选」
- 「新闻汇报」
- 「生成资讯报告」
- 「把最近看到的有价值的信息整理一下」

## 执行方式

执行完整 pipeline：

```bash
cd /root/.openclaw/workspace/skills/news-report/src && python3 main.py --full
```

采集完成后，将 `output/latest.md` 的内容发送给用户。

如果用户只提供了 RSS 文件路径，先读取文件内容，然后更新 `config/rss-sources.json`，再执行采集。

## 输出规则

1. 只发送报告正文（`output/latest.md` 内容），不发送代码或中间数据
2. 如果某一步骤失败，明确告知用户哪一步出了问题
3. 采集数量少时正常输出，不因数量少而报错
4. 评估阶段完全由模型自主判断，不询问用户

## 注意事项

- 用户未提供 RSS 文件时，跳过 RSS 采集步骤，继续 TG 和搜索
- 如果 BRAVE_API_KEY 不可用，搜索步骤跳过，TG + RSS 正常进行
- 整个流程静默执行，不需要实时播报进度
