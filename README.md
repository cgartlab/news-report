# miniflux-mcp-skill

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

Integrate the [Miniflux](https://miniflux.app) RSS reader into your AI agent via the `miniflux-mcp` MCP server — browse feeds and categories, search entries, and read unread/starred articles directly from conversations.

## Usage

The skill instructions live in [SKILL.md](./SKILL.md). Load the skill by name `miniflux-mcp-skill` in your agent runtime.
